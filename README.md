# Gauss LP quadrature

This is an OpenTURNS-based (www.openturns.org) implementation of Ryu and Boyd algorithm described in

Ryu, E.K., Boyd, S.P. Extensions of Gauss Quadrature Via Linear Programming. Found Comput Math 15, 953–971 (2015). https://doi.org/10.1007/s10208-014-9197-9

The clustering algorithm is taken from

John D. Jakeman, Akil Narayan, Generation and application of multivariate polynomial quadrature rules, Computer Methods in Applied Mechanics and Engineering,
Volume 338, 2018. https://doi.org/10.1016/j.cma.2018.04.009.

It includes an option to force the mean point to be one of the integration nodes through a penalization, and come with several examples.
